Velero Cli (toolbox в свой namespace) +
Создать Бакет в s3 (контакт Никита Коротков) хранить последние 7 дней, текущие использование места на PVC + 30% запас +
Инструкция в конфлюенсе


NS - tech-confluence-jira
User CEPH - obcr-idp-global-security-confjira
Backet CEPH - obcb-idp-global-security-confjira-data-bucket
Размер Bucket - 200 Гб

Все PVC на данный момент используют 10ГБ ( 7 дней хранения это 10*7=70 ГБ)

Role и Rolebinding в ns Velero

Один лейбл на все PVC

velero.io/volume-group: tech-confluence-jira-namespace


Указать ns - cpaas-system

Тестовые команды
velero backup create resources-only-new --include-namespaces tech-confluence-jira --snapshot-volumes=false --ttl 10m --namespace tech-storage --storage-location backupstoragelocation-isec
velero backup get --namespace tech-storage
velero backup describe velero-backup-isec-confjira-daily-20260917010037 --namespace tech-storage

kubectl get pvc -n velero-backup-isec-confjira-manual-20260916 --show-labels

velero backup delete velero-backup-isec-confjira-new-20260916 --namespace tech-storage --confirm

Основной бэкап
velero backup create velero-backup-isec-confjira-manual-$(date +%Y%m%d) \
  --include-namespaces tech-confluence-jira \
  --exclude-resources events,events.events.k8s.io,gateways.gateway.networking.k8s.io,httproutes.gateway.networking.k8s.io \
  --snapshot-move-data=true \
  --namespace tech-storage \
  --ttl 168h \
  --storage-location velero-bsl-isec-confjira
  
  
  
Восстановление
velero restore create confluence-jira-restore-$(date +%Y%m%d) \
  --from-backup confluence-jira-backup-20260911 \
  --namespace-mappings tech-confluence-jira:tech-tmp-confluence-jira \
  --namespace cpaas-system
